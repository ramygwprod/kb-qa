# Archive

Session records. Each one is the context that `CHANGELOG.md` and
`docs/DECISIONS.md` cannot carry: what the work turned out to be, what was open
when it stopped, and what the session that wrote it was wrong about.

Not documentation. A record here describes a moment and is never updated —
if something in it becomes untrue, that is a fact about the record's date, not
a defect to correct. Documentation lives in [`docs/`](../docs/README.md) and is
kept current.
